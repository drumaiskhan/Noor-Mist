You are a senior full-stack developer.

Upgrade my existing Noor Mist e-commerce website with a complete Pakistan payment system.

Tech Stack:

* React + Vite
* Express.js
* PostgreSQL
* Cloudinary
* Netlify Frontend
* Render Backend

DO NOT break any existing functionality.

The admin panel already exists and everything must be manageable from the admin dashboard.

---

# 1. Payment Methods

Create a flexible payment system supporting:

* Cash on Delivery (COD)
* Bank Transfer
* EasyPaisa
* JazzCash
* Sadapay
* Nayapay
* Raast
* Debit/Credit Cards (future-ready)
* Manual Payment Methods

The admin can enable or disable any payment method without changing code.

---

# 2. Payment Settings (Admin)

Create a new "Payment Settings" page.

The admin can:

* Enable/Disable each payment method
* Change display order
* Upload payment logos
* Change payment instructions
* Add payment notes
* Set minimum order amount
* Set maximum order amount
* Restrict payment methods by city or province
* Enable or disable COD

Everything must save in PostgreSQL.

---

# 3. Bank Accounts

Admin can add unlimited bank accounts.

Fields:

* Bank Name
* Account Title
* Account Number
* IBAN
* Branch Name
* Branch Code
* Swift Code (optional)
* QR Image
* Logo
* Instructions
* Active/Inactive

Support multiple accounts.

Customers only see active accounts.

---

# 4. EasyPaisa

Admin can edit:

* Account Name
* Mobile Number
* QR Code
* Instructions

Upload QR image.

# 9. Manual Payment Verification

After selecting Bank Transfer, EasyPaisa, JazzCash, Sadapay, Nayapay or Raast:

Customer uploads:

* Payment Screenshot
* Transaction ID
* Sender Name
* Sender Number
* Date
* Optional Notes

Store everything securely.

Delete old files automatically when replaced.
