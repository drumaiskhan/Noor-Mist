# Complete Admin-Controlled Website Management System

You are a senior full-stack developer. Upgrade my existing e-commerce website so that **every piece of content, design, branding, and configuration can be managed from the Admin Panel** without editing code.

## General Rules

* Do NOT break any existing functionality.
* Keep the current database structure where possible.
* Use the existing authentication system.
* Reuse the existing Settings architecture instead of creating separate systems.
* All changes must apply instantly after saving.
* All settings must persist in the database.
* Add validation for every field.
* Add reset-to-default buttons.
* Every upload should support JPG, PNG, WEBP and SVG where appropriate.
* Images should automatically optimize and compress.
* Support Cloudinary or local uploads.
