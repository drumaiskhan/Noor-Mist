# Noor Mist — Complete Production E-Commerce Website

You are a senior full-stack software engineer, UI/UX designer, database architect, SEO specialist, and performance engineer.

Build **Noor Mist**, a premium luxury perfume e-commerce platform.

Do **NOT** build a demo.

Build a real production-ready website.

Do **NOT** remove any existing functionality unless it is broken.

Improve the existing project without breaking routes, APIs, database connections, or the admin panel.

---

# Technology Stack

Frontend

* React + Vite
* Tailwind CSS
* Framer Motion
* React Router
* Zustand
* Axios
* React Query

Backend

* Node.js
* Express
* PostgreSQL
* JWT Authentication
* Cloudinary
* Multer

Hosting

* Frontend → Netlify
* Backend → Render
* Database → PostgreSQL
* Images → Cloudinary

---

# PRIORITY

The website must be

* Mobile First
* Extremely Fast
* SEO Optimized
* Accessible
* Luxury Looking
* Highly Animated
* Admin Controlled

Desktop should adapt from mobile—not the other way around.
