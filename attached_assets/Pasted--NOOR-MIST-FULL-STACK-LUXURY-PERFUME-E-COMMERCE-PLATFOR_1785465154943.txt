# NOOR MIST — FULL STACK LUXURY PERFUME E-COMMERCE PLATFORM

You are a senior full-stack developer, UI/UX designer, database architect, DevOps engineer, SEO specialist, and performance engineer.

Build a complete production-ready luxury perfume e-commerce website called **Noor Mist**.

This is NOT a demo.

Do not create placeholder pages.

Do not leave empty files.

Every component, route, API, database model, and admin feature must be functional.

Build it with a scalable architecture.

---

# TECH STACK

## Frontend

* React + Vite
* Tailwind CSS
* Framer Motion animations
* React Router
* Zustand state management
* React Query
* Axios
* React Helmet SEO

## Backend

* Node.js
* Express
* PostgreSQL
* JWT authentication
* bcrypt password security
* Cloudinary image storage
* Multer uploads

## Deployment

Frontend:
Netlify

Backend:
Render

Database:
PostgreSQL

Images:
Cloudinary

---

# MAIN GOAL

Create a premium perfume store similar to international luxury fragrance websites.

Priority:

1. Mobile experience
2. Speed
3. Luxury UI
4. Smooth animations
5. Admin control
6. SEO

Everything should be editable from admin panel.

No important content should be hardcoded.
